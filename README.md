# ffrace-decomp

Порт игры **Fast Future Race** (FFRace, Windows Mobile / Pocket PC, экран 240x320) на C89 + SDL2.

Код порта - собственный, написан по результатам реверс-инжиниринга оригинального
`FFRace.exe` (ARM PE). Из оригинальной поставки в репозиторий входят только ассеты
(`BITMAP`, `Sounds`, `Musics`) - без бинарников и без декомпилированных исходников.

Тот же движок использует JumpyBall - его порт лежит в
[jumpyball-decomp](https://github.com/Katamaran21/jumpyball-decomp).

## Что реализовано

- Псевдо-3D дорога: построчная проекция, тайловая заливка полотна, бордюры, ворота,
  небо и рельеф - десять оформлений трасс.
- Физика корабля: руление, тяга и тормоз, инерция, столкновения со стенами, накопление
  повреждений, таблица управляемости на шесть корпусов.
- Пять соперников на трассе, стартовая решётка, отсчёт `3-2-1-GO`.
- HUD: полоса скорости, полоса повреждений, позиция в гонке, таймер, иконка корабля -
  оригинальным шрифтом из ассетов.
- Меню: главное, Practice, выбор трассы, выбор корабля, Settings (Sound / Gameplay),
  About, прощальный экран.
- Звук: десять эффектов WAV, петля двигателя с изменением высоты тона от скорости,
  музыка `.tkm` (4-канальный ProTracker) собственным микшером.
- Ввод: клавиатура и опциональный экранный D-pad (SDL2 touch).
- Все трассы и корабли открыты сразу (см. «Отличия от оригинала»).

## Сборка

### CMake (Windows / Linux / любая платформа с SDL2)

```
cmake -S . -B build-cmake -DCMAKE_BUILD_TYPE=Release
cmake --build build-cmake
```

SDL2 ищется тремя способами по очереди: `find_package(SDL2 CONFIG)`, затем
`find_package(SDL2)`, затем `pkg-config`. Если ничего не нашлось - CMake сообщает об
этом и останавливается. На Linux достаточно `libsdl2-dev`, на Windows - vcpkg
(`vcpkg install sdl2:x86-windows`) с `-DCMAKE_TOOLCHAIN_FILE=<vcpkg>/scripts/buildsystems/vcpkg.cmake`.

Опции: `FFRACE_WARNINGS` (полный набор предупреждений, ON), `FFRACE_COPY_ASSETS`
(копировать `BITMAP`, `Sounds`, `Musics` рядом с бинарником, ON).

На Windows есть готовая обёртка со зашитыми путями к vcpkg-сборке:

```
build-cmake.cmd
```

### MSVC напрямую

```
build.cmd
```

Собирает `build\ffrace.exe` (`cl /W4 /O2 /TC /MT`, `/SUBSYSTEM:WINDOWS`) и копирует
рядом `SDL2.dll` и все ассеты.

### Проверка на соответствие ANSI C (C89)

```
tools\c89check.cmd
```

Прогоняет каждый `ff_*.c` через clang-фронтенд с `-std=c89 -pedantic-errors -Wall`,
ничего не компилируя - ловит то, что MSVC принимает, а строгий C89-компилятор нет.
Печатает `C89 OK` при успехе.

## Управление

В гонке - клавиатура:

| Клавиша | Действие |
|---|---|
| `Left` / `Right` | руление |
| `Up` | тяга |
| `Down` | тормоз |
| `Esc` | выход из гонки, назад по меню |

В меню - мышь (клик = тап стилусом, как в оригинале).

Экранный D-pad включается переменной окружения `FFRACE_TOUCH` (на Android он включён
всегда); в этом режиме окно можно свободно масштабировать.

## Ассеты

| Каталог | Содержимое |
|---|---|
| `BITMAP` | 102 файла `.bmp` - спрайты, шрифты, панели меню, тайлы трасс |
| `Sounds` | 10 файлов `.wav` - эффекты и петля двигателя |
| `Musics` | 11 файлов `.tkm` - `mainmenu`, `menucareer`, `course1`..`course9` |

Ищутся рядом с исполняемым файлом. Путь можно переопределить переменной окружения
`FFRACE_ASSETS`.

## Аргументы командной строки

| Аргумент | Действие |
|---|---|
| `<число>` | масштаб окна (по умолчанию 2) |
| `--dump=FILE` | записать кадр как сырой RGB565 (240*320*2 = 153600 байт) и выйти |
| `--dump-frame=N` | на каком кадре снимать дамп (по умолчанию 60) |
| `--activate=A,B,C` | нажать пункты меню по номерам, без участия мыши |

`--dump` и `--activate` сделаны для автоматической проверки экранов без человека за
монитором. `tools/raw2png.py` переводит сырые кадры в PNG.

## Отличия от оригинала

- **Открыты все трассы и корабли.** В оригинальном образе ни одна инструкция не
  записывает две переменные прогресса, поэтому retail-сборка показывает только первую
  трассу и первый корабль. Порт выставляет им значения «всё пройдено» перед показом
  главного меню; сами шесть проверок прогресса оставлены побайтово как в ROM. Побочный
  эффект, тоже как в оригинале: «Random» теперь выбирает из всех десяти оформлений.
- **Музыка в меню молчит до первой гонки** - это поведение оригинала, воспроизведено
  как есть.
- Гоночный трек запускается один раз, тогда как оригинал переотправляет команду
  воспроизведения каждые 60 секунд: поведение системного проигрывателя при повторном
  запуске не проверено.
- Не подключены два звука, у которых в оригинале нет достижимого триггера: взрыв по
  порогу повреждений (зависит от неразобранной анимации) и сирена (включалась только
  непортированным чит-переключателем).

## Чего пока нет

- Таблица результатов и итоговые места после финиша.
- Карьера (экраны Career / Garage): счётчик прогресса карьеры в оригинале тоже никем
  не записывается, все ветки идут по нулевому пути.
- Показ круга и контрольных точек.
- Экран переназначения клавиш.
- Анимация взрыва при критическом повреждении.
